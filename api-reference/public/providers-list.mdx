---
title: "List Providers"
openapi: "/api-reference/openapi.json GET /v1/public/providers"
description: "Get all available STT, LLM, and TTS providers with their supported models"
---

Use the returned catalog when choosing `provider_name` and `model_name` for a voice agent. The response groups models under `llm`, `stt`, and `tts`. Each provider maps to **an array of model objects**. Use the object’s `value` for the API and `label` for display. The LLM list is filtered to models selectable for voice.

```bash
curl 'https://api.eigi.ai/v1/public/providers' \
  -H "X-API-Key: $EIGI_API_KEY"
```

For example, to show the LLM options for OpenAI in a picker, iterate over `llm.OPENAI` and display each entry’s `label`. `total_count` contains the provider counts for each service. `timestamp` records when the response was generated.

Once you have chosen a TTS provider, [list its voices](/api-reference/public/voices-list) to find a voice ID.
