---
title: "List personal agent models"
openapi: "/api-reference/openapi.json GET /v1/eigi-agent/openai/models"
description: "Check that your enabled Eigi Computer is reachable and read its model IDs."
---

Use a platform API key belonging to the account that owns the running computer. Look for `eigi-agent` in `data[].id`. The configured model ID, when present, also reaches the same agent. [Enable the API or use a local Desktop address](/eigi-agent/developer-api).
