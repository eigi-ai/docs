## Overview

Retrieve available voices from a specific TTS provider. Use this endpoint to find the right `voice_id` for your agent's TTS configuration.

Supports filtering by language, gender, model, and search terms.

## Authentication

Send a platform API key in `X-API-Key` or an OAuth access token in the Bearer header. [Authentication](/api-reference/introduction).

## Query Parameters

<ParamField query="provider" type="string" required>
  Voice catalog to query. Providers include `CARTESIA`, `DEEPGRAM`, `ELEVENLABS`, `SARVAM`, `FISHAUDIO`, `GOOGLE`, `GROK`, `HUME`, and `OPENAI`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number (minimum: 1).
</ParamField>

<ParamField query="page_size" type="integer" default="20">
  Items per page (minimum: 1, maximum: 100).
</ParamField>

<ParamField query="language" type="string">
  Filter by language code (e.g., `en`, `hi`, `es`).
</ParamField>

<ParamField query="gender" type="string">
  Filter by gender: `MALE`, `FEMALE`, or `NEUTRAL`.
</ParamField>

<ParamField query="search" type="string">
  Search by voice name.
</ParamField>

<ParamField query="show_cloned_only" type="boolean" default="false">
  Show only cloned (custom) voices.
</ParamField>

<ParamField query="model" type="string">
  Filter by model (e.g., `bulbul:v2`, `bulbul:v3`).
</ParamField>

<ParamField query="page_token" type="string">
  Cursor for a provider that returns voice results in pages identified by a token.
</ParamField>

<ParamField query="next_page_tokens" type="string">
  JSON-encoded array of page tokens accumulated while browsing the provider’s results.
</ParamField>

## Read the result

Read `voices[].id` for the voice ID. Each entry contains its name, provider, language, status, clone flag, and provider metadata. Gender and ownership information may also be present.

The response includes `provider`, `page_size`, and `has_more`. For a provider with cursor pagination, retain the returned `next_page_tokens`. On the next request, send its page token as `page_token` and the accumulated list as the JSON-encoded `next_page_tokens` parameter. Keep filters the same while paging.
