## Overview

This endpoint creates conversations and initiates outbound calls via telephony provider (Plivo or Twilio) to specified phone numbers using your configured AI agent. You can initiate single calls or bulk calls by providing multiple phone numbers.

## Authentication

Send a platform API key in `X-API-Key` or an OAuth access token in the Bearer header. [Authentication](/api-reference/introduction).

## Request Body

<ParamField body="agent_id" type="string" required>
  The ID of the AI agent to use for the call. The agent must be owned by the API key holder and properly configured with LLM, TTS, and STT providers.

Example: `68ea2517dbb84c09bae1ba0a`

</ParamField>

<ParamField body="params" type="array" required>
  Array of call parameter objects. Each object represents one outbound call to
  initiate. Each item should have `mobile_number` (string, required) in E.164
  format and optional `metadata` object.
</ParamField>

<ParamField body="telephony_provider" type="string" default="PLIVO">
  Telephony provider to use for the call. Options: `PLIVO` or `TWILIO`

Defaults to `PLIVO` if not specified.

</ParamField>

<ParamField body="from_number" type="string">
  Choose an outbound number assigned to this agent. If omitted, the service selects one of its numbers.
</ParamField>

<ParamField body="is_test_call" type="boolean" default="false">
  Mark the call as a test so it can be excluded from reports.
</ParamField>

<ParamField body="retry" type="object">
  Retry settings for unanswered scheduled calls. `max_retries` accepts 0–5 extra attempts and `interval_minutes` accepts 5–1440 minutes.
</ParamField>

## Read the result

```json
{
  "status": "success",
  "message": "Outbound calls initiated: 2 successful, 1 failed",
  "successful_calls": 2,
  "failed_calls": 1,
  "failures": [{"mobile_number": "+12025550123", "error": "Failed to initiate call"}]
}
```

A successful response counts calls that were initiated. A mixed batch also includes `failed_calls` and `failures`. Inspect those entries before retrying a batch so that a recipient whose call started does not receive a second call.

To follow the outcome, [list conversations](/api-reference/public/list-conversations) using the agent ID, time range, and outbound calling type. Use the `conversation_id` from a matching conversation to [retrieve its transcript](/api-reference/public/get-conversation).

## Example

Use a configured outbound agent, one of its assigned numbers, and a recipient you intend to call. The example assumes you have set `EIGI_API_KEY` in your environment. Replace the agent ID and example number before sending.

```bash
curl 'https://api.eigi.ai/v1/public/calls/outbound' \
  -H "X-API-Key: $EIGI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"agent_id":"YOUR_AGENT_ID","params":[{"mobile_number":"+12025550123","metadata":{"topic":"appointment confirmation"}}]}'
```
