## Work from a terminal

Use `eigi-agent` to chat with your personal agent, resume a session, or run a task in a project folder. The platform CLI manages hosted voice agents, prompts, and calls. [Personal agent CLI](/eigi-agent/terminal) · [Platform CLI](/cli/introduction) · [MCP server](/mcp/introduction) · [Claude Code plugin](/plugins/introduction).
