## Work on a folder

Start a chat with the folder you want Eigi to use. Attach a document or mention a file in the composer, then ask for a specific result. For example, “Read these two proposals and save a comparison table in this folder.” Open **Files** to read the result. Use the terminal pane when you want to run a command yourself.

During a turn, send a correction to steer the work, or queue a follow-up with **Cmd/Ctrl + Enter**. Press **Esc** twice to stop the turn. Type `/` to see commands offered in that chat. In a started chat, `/side` opens a side question. Use `/goal` to give the chat an outcome to work toward.

## Bring an app into the chat

| What you want | Where to start |
| --- | --- |
| Ask about an open window | In **Settings → Appshots**, check the capture shortcut. Capture the window, review the image and any captured text, then send it in chat. |
| Have Eigi navigate a website | Open **Settings → Browser and extension** to choose the available browser setup. In chat, ask Eigi to open a page and find a detail. |
| Have Eigi interact with a desktop app | Where available, enable **Settings → Computer use → Use apps on this computer**. Complete the system permission prompts. Review the app access request and the stop shortcut shown in settings. |
| Read from a connected service | Open **Settings → Plugins → Connectors**, choose the service and authorize access. Ask for one item you recognize to check the account. |
| Add a reusable workflow | Open **Settings → Plugins** to inspect a bundle, or use the **Skills** tab. Choose which agents may use it. |

For a walkthrough of the app permission prompt and the global stop shortcut, see [Use a desktop app with Eigi](/eigi-desktop/apps).

## Review a code change

Open a repository folder and ask for one small change. Open the review pane to inspect the files and their diffs. For a chat that needs a separate working copy, choose a worktree when starting it. **Settings → Worktrees** controls worktree preferences and **Hooks** manages setup scripts. Follow [Projects, documents, and code review](/eigi-desktop/projects) to review a branch or pull request.

## Choose a model or use voice

Open **Settings → Models and providers** to see the accounts and models available to this computer. Choose the default for new chats or use the model picker in a chat. The [terminal client](/eigi-agent/terminal) can also list models and show the effective configuration for a folder.

Use the microphone in the composer to dictate a message. Review the draft before sending it. In **Settings → Tools**, inspect the image and speech tools offered to the agent. For example, ask for an illustration to go with a document when image generation is enabled.

## Schedule work and check the result

In chat, ask “Every weekday at 9 AM, summarize the notes in this folder.” Specify your time zone and where you want the result. Open **Automations** to review the schedule and its runs. Local automations need the computer awake and the engine running. Under **Settings → General → Power**, review **Keep computer awake while Eigi works** and its battery setting. Closing the window can leave Eigi in the tray. Quitting the app stops its app-managed engine.

## Manage what carries over

Use **Settings → Memory** to inspect what Eigi remembers and change its memory settings. Chat history and remembered facts have separate controls. Under **Permissions**, review the actions Eigi can take and the access you have granted. **Balance and usage** shows account usage. **Keyboard shortcuts** and **Appearance** let you adjust the workspace to fit how you work.
