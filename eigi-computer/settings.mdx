Open **Settings** inside Eigi Computer. Settings here apply to the cloud workspace you have open.

| To change… | Open… |
| --- | --- |
| Time zone, chat preferences, or notifications | **General** or **Notifications** |
| The default model or provider account | **Models and providers** |
| Instructions and preferences about you | **Personalization** |
| What Eigi remembers, or which channel identities belong to one person | **Memory** or **People** |
| Which actions need approval | **Permissions** |
| How specialists work or who can delegate to them | **Buddies and Rooms** or **Subagents** |
| Installed workflows and connected services | **Skills**, **Plugins**, or **Connectors** |
| Messaging accounts or sharing with another user | **Channels** or **Network**, when available |
| Credits, usage, computer power, renewal, or backup | **Balance and usage** or **Computer** |
| API access or a configuration problem | **Developer API**, **Health**, or **Change history** |

## Review permissions

Under **Permissions**, **Ask first** pauses for approval before changes such as sending a message. **Auto** has a checker review ordinary work, while **Full access** lets ordinary actions run and sends dangerous ones to the checker. Read the description of each mode before choosing it. For people reaching Eigi through a channel, review their **Standard**, **Trusted**, or **Custom** access separately.

To let a friend use a particular Buddy, follow the [sharing steps](/eigi-agent/registry). To let an application talk to the running computer, [enable its Developer API](/eigi-agent/developer-api).
