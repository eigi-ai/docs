Open **Automations** on a running Eigi Computer. Choose **Main** for the computer’s schedules and incoming triggers, or choose a Buddy to see its routines.

## Schedule a first task

1. In chat, ask “Every weekday at 9 AM in Europe/London, send me a reminder to review my notes.” Include the destination if you want a connected channel to receive it.
2. Open **Automations → Schedules** for Main, or **Routines** for the Buddy. Review the saved instructions, time, and delivery destination. You can also create the schedule here.
3. After the scheduled time, inspect the run history. Execution records tell you whether the task ran. Delivery status tells you whether the result reached the chosen chat.
4. Pause a schedule when you want to keep its settings for later. The cloud computer needs to be running when you expect it to do the work.

## Trigger a task from another service

For example, a GitHub repository can notify your Eigi Computer when an issue opens.

1. Choose **Main → Triggers → New trigger** in Automations. Configure the route and what should happen to an incoming event.
2. Copy the URL into the sending service’s webhook settings. Configure the route’s signing secret there too. A GitHub sender can sign deliveries using its webhook secret.
3. Send a test event, inspect the sender’s delivery status, and check the resulting action in Studio.

The URL routes the event to your computer. The signature verifies the sender. For signature headers and HTTP results, see [Trigger an agent webhook](/api-reference/public/agent-webhook).
